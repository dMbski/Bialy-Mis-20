
# Bialy-Mis-20 (White Bear 2.0)

Biały Miś 2.0 - program do sprawdzania kontrahenta na "białej liście" podatników VAT, oraz automatycznego zapisywania potwierdzeń weryfikacji.
Program for verification of the contractor on the "White List" of Polish VAT taxpayers. This aspect of doing business concerns Polish companies.

Program do weryfikacji kontrahenta na "Białej Liście" podatników VAT (https://wykazpodatnikowvat.mf.gov.pl/).
Wynik pozytywnej weryfikacji, automatycznie zapisywany jest na dysku komputera.

Dzięki elektronicznemu przechowywaniu wyników z ich unikalną sygnaturą (nadawaną przez system Ministerstwa Finansów) unikasz niepotrzebnych wydruków papierowych.

Domyślnie zapisywane są wyniki pozytywne, czyli podatnik jes w statusie Czynny oraz posiada przynajmniej jedno konto bankowe. Oczywiście z poziomu programu, wynik można wydrukować lub zapisać do wskazanego pliku.
